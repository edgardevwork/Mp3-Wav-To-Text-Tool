* **This is a free tool for converting MP3 or WAV files into text.**

 It was designed to convert audio lasting more than 15 minutes, as this is the limit for most free services. Everything is simple here: you can run it via PyCharm, provided you don’t forget to change the language in line 21 (“language="ru""). I recommend using the “base” or “large-v3-turbo” model.

To use it, download FFmpeg to the FFmpeg folder and unpack it.

---
**Requirements:** 
- Python 3.10+ 
- PyCharm

---
**FFmpeg is used here:**
ffmpeg-n9.0-latest-win64-gpl-9.0
[https://github.com/BtbN/FFmpeg-Builds/releases](sources=[])
